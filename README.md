# 镜叙｜电影关键帧导演

当前版本：v1.3.2。将画面想法转为电影静帧，支持连续组图与图片诊断修复。

本版保持原有范围与验收门槛，将信息层级和模型转译并入提示词契约，减少入口与参考分支。

## 使用

将本目录复制到 `%USERPROFILE%\.codex\skills\jingxu-cinematic-keyframes`，在新任务中调用：

```text
$jingxu-cinematic-keyframes
写一个电影静帧提示词：主题、人物与场景……
必须保留：……
画幅：……（可选）
```

默认给中文决策和一个英文提示词；可指定其他语言。只有请求生成或编辑时才调用图像工具。
