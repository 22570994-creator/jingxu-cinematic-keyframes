# 镜叙｜电影关键帧导演

镜叙是一个面向 AI 图像与视频创作者的 Codex Skill，服务电影感单帧、封面、图生视频关键帧与连续镜头生产。它不靠堆叠“电影感”形容词，而是把故事拍点、画幅、信息层级、光线、材质、受力、接触和连续性写成可执行、可检查的生成指令。

当前版本：`v1.2.1`

公开仓库：<https://github.com/22570994-creator/jingxu-cinematic-keyframes>

## 它解决什么问题

- 生成结果好看，但像壁纸、海报或广告，没有正在发生的事件。
- 图文、轮播和视频关键帧机械套用竖图，关键人物关系或落点被裁掉。
- 同一人物跨镜头时换脸、换衣、换道具或改变光向。
- 高速动作只有姿势，没有当前支撑、下一接触点和可验证运动空间。
- 修图时整张重抽，把已经通过的部分一起破坏。

镜叙会根据发布硬规格、运动轴、人物关系和空间尺度自动选择母版画幅；失败时只修复一个最高影响变量，并列出必须保持不变的项目。

## 安装

### 方式一：复制到 Codex Skills 目录

1. 下载或克隆本仓库。
2. 将仓库文件夹复制到：

```text
%USERPROFILE%\.codex\skills\gpt-image-2-cinematic-keyframes
```

3. 在新任务中直接描述电影关键帧、图文首图、连续镜头或失败诊断需求；也可以显式调用：

```text
$gpt-image-2-cinematic-keyframes
```

### 方式二：从 GitHub 安装

在支持 GitHub Skill 安装的 Codex 环境中，选择本仓库根目录作为 Skill 路径；根目录已包含 `SKILL.md`。

## 最少输入

```text
请用镜叙：
主题或选题：
主体：
场景与时间：
正在发生的动作：
发布形态：图文首图 / 轮播 / 视频关键帧
必须保持：
不要出现：
```

## 标准输出

1. 故事拍点、第一眼信息、发布形态和画幅决策。
2. 一个可直接复制的英文生产提示词。
3. 移动端缩略图、裁切和文字风险检查。
4. 连续镜头需要的 `continuity_lock`。
5. 失败时的一次单变量修复提示词与复测结论。

## 使用边界

- 不点名复制具体电影、导演、在世艺术家、品牌或摄影作品。
- 不承诺爆款、点击率、平台推荐或商业发布许可。
- 生成图、提示词和测试报告不自动等于真实客户案例。
- 公开发布前，仍需确认人物、场地、素材和商用权利，并按平台要求标注 AI 生成内容。
