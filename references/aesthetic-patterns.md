# 电影感审美模式

这些模式按故事功能选择，不按“像哪部电影”选择。先确定事件、人物关系和可见证据，再借用模式；一张图通常使用一个主模式，最多叠加一个辅助模式。

## 先过信息层级门

任何模式都先写清三层：

- **清晰主体**：第一眼必须读取的人、动作、接触或关键物。
- **支持层**：第二眼补充人物关系、空间用途或运动方向，降低一档细节与对比。
- **安静场**：低信息区域，但必须承担尺度、等待、压力、视线方向或下一拍留白；没有任务就不是留白。

前景遮挡只有在它能证明摄影机观察位置、人物关系或空间隔离时才保留。强欠曝、过曝、雾和反射每镜只采用一个主要逻辑，并说明哪些信息可以消失、哪些轮廓必须保留。完整方法见 [信息层级方法](perceptual-hierarchy.md)。

## 快速选择

| 用户真正需要什么 | 主模式 | 首要控制 |
|---|---|---|
| 普通人的尊严、工作、生活重量 | 人文纪实劳动（documentary labor） | 具体劳动和使用痕迹 |
| 人静止而外界持续变化 | 私密交通空间 | 玻璃、反射、内外位移 |
| 两人关系紧张但不靠打斗 | 局促空间冲突 | 视线轴、距离、遮挡、道具 |
| 都市夜景但要摆脱赛博模板 | 受控霓虹黑色电影 | 一个暖色焦点与真实地点功能 |
| 童年、家庭录像、回忆残片 | 慢电影与记忆（memory） | 具体的不完美摄影 |
| 渺小人物面对巨大环境 | 巨物尺度与孤人 | 人物比例、任务和单向光 |
| 现实中只有一处轻微异常 | 诗性超现实 | 一个材质真实的异常规则 |
| 历史、仪式、民俗悬疑（folk suspense） | 东方历史与民俗 | 时代物证、礼仪关系、实景光 |
| 竞技、跳跃、追逐或文化表演 | 高速动作与受力 | 支撑、轨迹、阶段、落点、刚性层 |

## 1. 人文纪实劳动（documentary labor）

**故事功能：** 人物通过具体劳动暴露处境、技能或尊严，而不是站在工作环境里摆拍。

**需要写清：**

- 当前只完成到一半的动作，例如倾倒、整理、修补、夹起、擦拭或搬运。
- 工具如何被握持、重量如何改变姿态、工作台或地面的使用痕迹。
- 污渍、潮气、皱纹、磨损、汗、冰、水、绳网等物质证据。
- 一冷一暖的真实光源关系，例如晨光与工作灯。

**运动层：** 手部劳动；呼吸、蒸汽或液体；背景的低幅度环境变化。复杂对象很多时只让局部继续运动。

**避免：** 时尚姿势、商业食品摆盘、过度磨皮、工具和手没有接触关系。

## 2. 私密交通空间

**故事功能：** 封闭车厢、船舱或候车空间把人物困住，外界位移表达时间或心理。

**需要写清：**

- 人物做什么微小但可读的事，并指定目光对象。
- 玻璃划痕、凝结水汽、暗反射与外部光轨的几何关系。
- 内部实景灯和外部环境光各自的颜色与方向。
- 前景座椅或门框形成的遮挡和空间深度。

**运动层：** 外景单向位移；反射小幅漂移；人物呼吸或视线变化。

**避免：** 把反射误写成第二个人、加入手机或票据等高风险文字道具、用大量散景掩盖环境。

## 3. 局促空间冲突

**故事功能：** 用空间关系表达冲突，不依赖武器、哭喊或夸张表情。

**需要写清：**

- 双方距离、朝向、眼线目标，以及谁刚完成一个动作。
- 承担矛盾的唯一道具及其位置，例如封闭信封、钥匙或未动的饭碗。
- 门框、家具或蒸汽如何在前后景分隔两人。
- 荧光灯、灶灯、走廊灯等实景光源的权力关系。

**运动层：** 手从道具旁收回；蒸汽或灯光微变；克制呼吸或衣摆落定。

**避免：** 镜面对称站位、两人都看镜头、无因果的戏剧表情、为了“危险”随意添加刀具。

## 4. 受控霓虹黑色电影

**故事功能：** 用夜间城市环境压迫人物，同时让一个颜色或实景灯承担叙事焦点。

**需要写清：**

- 地点真实功能，例如修车巷、夜班装卸区、旧影院后门，而不是抽象赛博城市。
- 一个主要暖色焦点，其余区域服从冷暗环境。
- 湿地、雨丝、蒸汽与背光轮廓的因果关系。
- 无文字版本的灯箱或明确、短小且可控的文字内容。

**运动层：** 人物前进或停步；雨或蒸汽；一个实景灯轻微闪动。

**去套路：** 在人物身份、地点功能和冲突事件中至少替换两项；不要套用“美女 + 红衣 + 蓝红霓虹 + 雨巷”。

## 5. 慢电影与记忆（memory）

**故事功能：** 让观察的迟疑和影像缺陷成为记忆真实性，而不是加一个复古滤镜。

**需要写清：**

- 摄影者的具体位置或身份，例如儿童手持家用摄像机。
- 轻微倾斜、迟到的构图、局部裁切、焦点略迟、柔软解析或轻微过曝中的两到三项。
- 与时代一致的家具、衣料、器具和照明。
- 人物注意力落在真实动作或物件上，而不是镜头。

**运动层：** 树影、热浪、晾晒物或窗帘；一次家庭小动作；几乎不可见的手持漂移。

**避免：** 金色奢华怀旧、整齐家庭合影、只写 `vintage` 或 `nostalgic`、混入不合时代的塑料制品或手机。

## 6. 巨物尺度与孤人

**故事功能：** 用人物占比和环境层级表达渺小、任务或压力。

**需要写清：**

- 人物为何来到这里，以及一个远距离仍可读的任务或道具。
- 地貌或建筑的前中后景尺度，人物在画面中的明确比例。
- 单一方向光、稀薄色彩和空气透视。
- 一条可执行的镜头路径，通常为慢推或横移。

**运动层：** 脚步或停顿；衣物或扬尘；远景气流。

**避免：** 巨日、橙色荒漠、无身份孤人这一整套模板；环境只有“大”而没有任务。

## 7. 诗性超现实

**故事功能：** 一个熟悉劳动、物件或自然现象承担隐喻，异常只发生在一个层级。

**需要写清：**

- 完全可信的日常环境和人物动作。
- 唯一异常规则、它影响什么、它不影响什么。
- 异常元素仍有重量、湿度、纤维、反射或磨损等真实材质。
- 人物对异常的克制反应，而不是夸张惊叫。

**运动层：** 异常物件的局部变化；环境介质；人物一次细小反应。

**避免：** 发光粒子、漂浮杂物、多个超自然规则同时出现、为了“诗意”删除物理接触。

## 8. 东方历史与民俗悬疑（folk suspense）

**故事功能：** 用信仰、礼仪和空间秩序建立悬疑；文化细节优先于仙气和特效。

**需要写清：**

- 地区、年代和社会身份足以决定衣料、建筑与器物。
- 人物处在礼仪或空间秩序中的位置和视线目标。
- 油灯、烛火、门窗、雨光等实景光源。
- 如有异常，只给一个方向一致、可观察的规则。

**运动层：** 烟、火焰或帘幔沿同一方向；人物停步或回望；门外天气。

**避免：** 伪文字符咒、红十字或宗教标志误触发、发光法器、幻想盔甲、满月与漂浮粒子的通用组合。

## 9. 高速动作与受力

**故事功能：** 让观众读懂力量从哪里来、主体正去哪里，而不是只看到夸张姿态。

**需要写清：**

- 起跳、转身、碰撞或落地前的唯一阶段。
- 起点支撑、画面内运动方向、目标接触点和禁止出现的额外接触。
- 参与者准确数量；多人共用服装、车辆或器械时解释结构关系。
- 毛发、衣料、尘土或水花应落后于主体运动方向。
- 钢桩、建筑、地面、车辆等刚性层保持直线和固定几何。

**运动层：** 主体单一轨迹；一层材料滞后；一个跟拍、摇摄或固定机位策略。

**避免：** 同一帧混合起跳和落地、方向含混、多个支撑点、背景跟着主体弯曲、用火焰或粒子伪造速度。

## 混合模式规则

需要混合时，先写主模式的事件和物理，再借辅助模式的一项摄影语言。例如：

- 人文劳动 + 诗性超现实：劳动必须先真实，异常只改变一个物件规则。
- 民俗悬疑 + 局促冲突：礼仪空间是主结构，视线和距离承担人物关系。
- 高速动作 + 记忆：动作物理保持清楚，只让画质和取景呈现家用录像的不完美。

如果两个模式各自要求三层运动、两个异常或两套色彩焦点，删除辅助模式。

同样删除第二套信息层级：辅助模式可以贡献一项摄影语言，但不能再创建另一个同等清晰主体、另一个安静场或第二个极端曝光逻辑。
