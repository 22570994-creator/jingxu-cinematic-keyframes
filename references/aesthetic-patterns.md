# 审美方向

仅在需要选方向时加载。选一个主要方向，最多融合一个有明确用途的辅助方向；不用风格库堆满提示词。

| 方向 | 可观察的组织方法 | 避免 |
|---|---|---|
| 劳动现场 | 手、工具与工作痕迹构成事件；侧光揭示磨损 | 摆拍劳动、无用途污渍 |
| 私密旅途 | 窗框或座位分隔人物，环境反光支持情绪 | 无来源霓虹与泛滥雨滴 |
| 狭窄关系 | 门框、桌面与人物距离表达压力 | 无理由拥挤、所有人同样抢眼 |
| 克制夜色 | 单一主色光有具体招牌或灯具来源 | 满屏互相冲突的彩色光 |
| 记忆质感 | 一件旧物与少量材质磨损承载时间 | 用泛黄滤镜代替故事 |
| 环境与人 | 尺度差、地形与人物位置体现孤独或归属 | 主体小到无法辨认关键行为 |
| 诗性超现实 | 一个明确不可能点，其他空间与材质可信 | 叠加多个无关联奇观 |
| 历史民俗 | 具体生活用途、材料工艺和空间关系 | 随机混搭年代与符号 |

输出时只保留能在图中指认的决定。若信息过满，按 [提示词契约](prompt-contract.md#层级与模型转译) 先删减，不追加风格词。
