# 小红书电影关键帧工作流

## 路由原则

先判断用户最终发布的是什么，再判断镜头的运动轴、人物关系和空间尺度；平台名称不是画幅答案。

## 自动画幅决策

按以下顺序选择母版画幅：

1. **发布硬规格**：用户或成片容器明确要求比例时服从；未明确时继续判断内容。
2. **运动轴**：横向运动、并行追逐、渡海和横向关系优先 `3:2`、`16:9` 或宽银幕；纵向运动、攀升、坠落、全身舞蹈和纵向空间优先 `3:4`、`4:5` 或 `9:16`。
3. **主体分布**：单人半身或上下层级关系可用竖幅；多人横向调度、视线链或环境尺度优先横幅；居中图腾式主体、对称物件或方形网格才选择 `1:1` 方形。
4. **派生需求**：需要信息流封面或标题版时，先保留最能承载动作关系的母版，再声明可安全裁切区域或另做重构版；不把唯一叙事证据硬塞进固定竖框。

组图默认使用一个共同母版比例，避免轮播跳框；只有建立镜头、特写等功能差异明确时才改变比例。每次输出写出一句画幅理由，例如“八仙横向渡海、两人并列和目标礁石需要同框，因此选择 `16:9`”。

| 发布形态 | 自动选择范围 | 关键控制 |
|---|---|---|
| 图文笔记首图 | `1:1`、`3:4`/`4:5`、`4:3`/`3:2`、`16:9` | 一秒主体、一个未完成事件、可选文字安全区；比例服从主体与动作 |
| 同主题轮播 | 全组统一的自动选择比例 | 同一视觉母题、人物与场景锁、每页只有一个计划变化 |
| 视频笔记关键帧 | 与最终视频容器一致；常见为 `9:16` 或 `16:9` | 为主运动方向留空间；派生裁切不得丢失接触和钩子 |
| 横版原片再发布 | 保留原叙事画幅 | 需要竖版封面时另做重构，不把横版关键关系硬裁掉 |

该默认值服务移动端生产，不是不可变的平台保证。用户指定发布规格时服从用户；平台界面或裁切规则变化时重新核验。公开参考：[小红书分享开放平台](https://agora.xiaohongshu.com/doc/ios)。

## 首图视觉钩子

首图的第一眼信息只能有一个。优先从内容本身选择：

1. **未完成动作**：跃起尚未落下、信封刚被推回、工具刚接触材料。
2. **关系张力**：两条视线通过一个道具闭合，人物与巨大空间形成尺度差。
3. **真实异常**：可信日常环境中只有一个规则轻微异常。
4. **材料证据**：雨水、绳结、磨损、蒸汽、手部受力直接证明事件。

不用无因果霓虹、满屏粒子、巨大标题或夸张表情制造假钩子。遮住文字后，画面仍应让用户看懂“谁、在哪里、正发生什么”。

## 单帧成片

1. 选择一个未完成事件和唯一清晰主体。
2. 将支持层降一档细节与对比，把安静场用于视线、尺度或下一拍空间。
3. 按自动画幅决策选择比例；用户需要标题时，在不损害主体和运动方向的一侧预留低纹理区域。
4. 生产提示词默认不生成文字。准确中文标题使用独立文字轮次，逐字指定内容、位置和保持项。
5. 用小红书量表检查缩略图、裁切和广告感，再决定是否生成文字版本。

## 连帧生产

第一镜建立 `continuity_lock`，包括人物、服装、道具、场景几何、主光方向、色彩结构和空白表面。后续镜头逐字复述，只改变景别、机位或一个下一动作拍点。

视频源帧需要派生信息流封面时，先声明目标裁切比例和位置，再把以下内容放进该安全裁切区：

- 人脸或主体识别特征；
- 当前动作的支撑面和目标接触点；
- 承担视觉钩子的道具或关系；
- 不能被裁掉的时代与文化证据。

上、下扩展区域用于天空、地面、运动预备空间或低风险环境，不放唯一叙事证据。图文轮播所有页面保持同一比例和母题，不把电影关键帧改造成信息卡片拼贴。

## 失败诊断

先回答四个小红书问题，再进入电影量表：

1. 缩成手机信息流尺寸后，第一眼还看得到主体和动作吗？
2. 自动选择的母版画幅是否有运动轴、人物关系或空间尺度依据；声明的派生裁切后关键关系是否完整？
3. 画面是否因完美皮肤、正中摆位、过亮轮廓或无使用痕迹而像广告？
4. 随机文字、伪徽章、平台标识或水印是否污染画面？

只修最高影响问题。首图主体太小就先改信息层级或机位；安全裁切失败就先重排主体与接触点；不要同时更换人物、光线和色彩。

## 输出形状

```text
发布模式：[图文首图 / 轮播 / 视频关键帧]
画幅与裁切：[自动选择的比例 + 一句可见理由 + 需要时声明派生安全区]
故事拍点：[当前未完成事件]
第一眼信息：[唯一主体或物理单元]
生产提示词：[一个英文提示词]
连续性锁：[仅系列或编辑需要]
移动端检查：[缩略图、裁切、文字、广告感]
下一轮：[通过即停止；失败只改一个最高影响变量]
```

## 边界

- 本工作流优化视觉资产，不负责小红书正文、话题、账号定位或发布动作。
- “首图可读”不等于有流量，“测试通过”不等于用户接受或商业发布就绪。
- 民俗、制服、现实人物和商业品牌涉及权利或事实核验时，保留人工确认门槛。
