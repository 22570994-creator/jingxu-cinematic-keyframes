# 图片诊断与修复

先看实际图片。只有提示词或用户描述时，给出待验证假设，不声称看到了缺陷。用户只要求诊断时，不自动调用编辑。

## 判断优先级

人数与身份 → 解剖、接触与空间 → 事件可读性 → 关键道具与场景事实 → 构图、光线和材质 → 微小瑕疵。
先处理最高影响问题；每轮后检查是否引入新错误。

## 先选路线

**局部编辑**：主体与空间结构成立，错误可以定位，如纸上伪字、衣袖徽章、某只手、局部过亮。指定区域和一个改变，保留相关已通过内容。工具支持局部蒙版才使用，不承诺像素完全不变。

**结构重建**：人数严重错误、人物融合、空间关系不可能、主要事件被替换，或局部修复会牵动全图。重新组织主体与构图，明确哪些正确事实仍保留；不得同时要求“修正人数”和“人数完全不变”。

编辑尝试无改善时重新判断路线，不无限重复同义提示词。重建会改变原图，应在用户仅授权局部修复时说明差异并取得方向确认。

## 常见诊断

| 可见问题 | 可执行改变 |
|---|---|
| 年龄偏离 | 改具体面部、手部或姿态特征，保留身份锚点 |
| 随机符号、伪文字 | 将对应表面改为连续素色布面或纸张背面 |
| 对视、手与物件关系错误 | 明确视线目标、左右手、接触位置；空间整体冲突则重建 |
| 人物像摆拍 | 改一个与事件相关的姿态或视线，减少无关装饰 |
| 塑料皮肤或材质过亮 | 局部调整反射和微纹理，保留主光逻辑 |
| 第一眼不明确 | 降低竞争区域细节或对比；必要时读信息层级参考 |
| 跨图漂移 | 依据组图契约核对身份或世界参考，勿混用 |

## 输出模板

```text
Observed issue: [visible evidence, or explicitly unverified hypothesis].
Route: [local edit / structural rebuild].
Change: [specific correction and region].
Preserve: [valid identity, count, placement, props, background and light anchors relevant to this edit].
Recheck: [target issue and likely side effects].
```

不生成空泛的完整不变量清单：只列本图适用且不与修复目标冲突的项。实际编辑后按验收量表复查；未见编辑结果则标为待验证。
