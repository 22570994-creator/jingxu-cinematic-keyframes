# 静帧验收与证据边界

看实际输出再评价。未生成、图片无法读取、区域被遮挡时分别标注，不以提示词中“已要求”代替图像证据。

## 必要检查

- 用户要求的人数、身份、物件与画幅是否满足。
- 人体、物件接触和空间关系是否可信；必要信息是否被裁掉。
- 第一眼能否识别主要事件或关系。
- 光源、材质是否自洽，有无影响主体的伪文字或随机符号。
- 组图额外检查每帧人数、跨帧身份、全组角色覆盖、场景与光向；单张记为不适用。

逐项用“通过 / 失败 / 无法确认 / 不适用”，并指明区域或帧号。用户明确要求的关键事实失败时不可用其他美感分数抵消。

## 报告与复查

### 不确定证据

- 小字、徽章或反光无法辨识时，“无可读文字”不等于“没有文字或符号”；严格禁字项应记为无法确认，并指明区域。
- 细亮线或光点可能是雨丝、颗粒或反光时，不凭整体气氛判定“没有下雨”。证据不足记为无法确认，不强行二选一。
- 分开核对用户原始要求和提示词自行补充的细节。补充细节未实现可报告，但不冒充用户关键事实失败。

### 编辑对照

先核对实际输入的图片版本；用户要求回到原图时，不用中间编辑结果代替。对照实际输入与输出，分别报告：目标改动是否实现、人物和叙事是否保留、非目标区域是否保持。

只改颜色等严格局部要求下，服装褶皱、物件形状、墙面或地面纹理的可见变化都是非目标漂移；“不影响叙事”不能抵消保留项失败。看不清则记为无法确认。视觉检查不能证明逐像素不变；没有像素级证据，不承诺无损编辑。

简述最高影响问题、局部编辑或重建路线、应保留项。编辑后核对目标缺陷与新增副作用。主观审美判断单列，不能伪装成客观通过率。

结构检查只证明包格式与引用可用；文本案例只能验证提示词行为；实际图片比较才提供本轮视觉证据。未做生成对比，不声称节省成本、提高成功率或画质。
